# Archived work

This repository holds completed feature records and reports for Kaon Chamber.
Active work belongs in the application's `docs/features/` and `docs/reports/`.

- Archive through the application's `feature-archive` skill. Preserve content
  except for link repairs and archive provenance. Keep document and requirement
  IDs unchanged, including paired specification and verification records.
- Historical records provide context, not current instructions or requirements,
  unless the user selects one as a task target.
- Preserve existing archives. Use a dated destination when the same path holds
  a different record.
- Never commit customer records, extracted text, model responses, corpus-derived
  artifacts, credentials, tokens, or raw tool payloads. Keep restricted evidence
  at its approved location and link to its recorded revision.
- Commit and push only the task's changes within the user's authorization.
- This checkout is shared across application worktrees. Preserve other tasks'
  changes; do not switch branches, reset, or stage unrelated files.
