# Kaon Chamber work

Archived feature designs, specifications, verification records, and reports for
[Kaon Chamber](https://github.com/KnowHow-Software-Inc/kaon-chamber).
Current decisions, development references, and deployment procedures stay in
the application repository.

Active work lives in the application's `docs/features/` and `docs/reports/`.
Use its `feature-archive` skill to publish completed folders here:

- `features/` holds completed feature records.
- `reports/` holds completed audits, research, and safe verification reports.

Keep historical records in place. New work starts in the application repository.
The application's `docs/README.md` defines the feature workflow.
